# 📱 Phone Flip

**Phone Flip** — игра-симулятор ремонта телефонов и собственного бизнеса на Python и Pygame. Покупайте подержанные устройства, диагностируйте неисправности, ремонтируйте их вручную и продавайте дороже. Развивайте мастерскую, открывайте новые модели, а затем переходите от перепродажи телефонов к созданию собственной компании.

## ✨ Возможности

- **Ручной ремонт телефонов.** Размягчайте клей спиртом, снимайте заднюю крышку, отключайте аккумулятор, удаляйте старые детали и устанавливайте новые перетаскиванием мышью. После этого соберите и приклейте корпус обратно.
- **Индивидуальные 3D-модели.** У телефонов отличаются корпуса, материалы, блоки камер, расположение кнопок и фронтальные элементы. Модели создаются средствами самой игры — отдельная 3D-библиотека не требуется.
- **Рынок и перепродажа.** Покупайте устройства с разным состоянием компонентов, вкладывайтесь в ремонт и продавайте телефоны покупателям.
- **Запчасти и расходники.** Внутриигровой магазин предлагает экраны, аккумуляторы, камеры, разъёмы зарядки и спирт для размягчения клея.
- **Развитие мастерской.** Улучшайте мастерскую до третьего уровня.
- **Собственная компания.** На позднем этапе доступны разработка моделей телефонов, производство, заводы, персонал и улучшения бизнеса.
- **Звук и музыка.** Звуковые эффекты и фоновая lo-fi музыка синтезируются программно, без обязательных аудиофайлов.
- **Настройки.** Управляйте громкостью, музыкой, анимациями, качеством 3D, сложностью ремонта, вращением моделей, полноэкранным режимом, FPS и автосохранением.
- **Русский интерфейс.**

## 🚀 Установка и запуск

### Требования

- Python 3.8 или новее
- Pygame 2.x

### Запуск

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/ВАШ-АККАУНТ/phone-flip.git
cd phone-flip
```

Установите зависимость:

```bash
python -m pip install pygame
```

Запустите игру:

```bash
python phone_flip_v4.py
```

Если команда `python` не срабатывает в вашей системе, попробуйте `python3`.

> Игра запускается из одного основного Python-файла. Звуки и музыка создаются кодом; при необходимости файл фоновой музыки кэшируется рядом со скриптом.

## 🎮 Как играть

Основной игровой цикл:

1. Купите телефон на рынке.
2. Оцените его состояние и решите, какие детали нужно заменить.
3. Приобретите необходимые запчасти и расходники.
4. Выполните ремонт в мастерской.
5. Продайте восстановленный телефон и получите прибыль.
6. Улучшайте мастерскую и постепенно открывайте новые возможности.

### Этапы ремонта

1. Размягчите клей: зажмите левую кнопку мыши и проведите флаконом со спиртом по периметру крышки.
2. Снимите заднюю крышку. При необходимости можно использовать `Пробел`.
3. Отключите аккумулятор.
4. Перетащите неисправные детали из корпуса в мусорку.
5. Перетащите новые детали со стола в соответствующие места корпуса.
6. Подключите аккумулятор и установите крышку.
7. Прижмите крышку по периметру, чтобы завершить сборку.

Следите за состоянием компонентов: ошибки во время ремонта могут повредить детали. Выбрать уровень сложности можно в настройках.

## ⚙️ Настройки

В меню настроек доступны:

- звуковые эффекты и их громкость;
- фоновая музыка и её громкость;
- включение анимаций и выбор их скорости;
- качество 3D-моделей;
- вращение моделей;
- сложность ремонта: лёгкая, нормальная или сложная;
- отображение FPS;
- полноэкранный режим;
- автосохранение.

На высокой сложности зона успешного вскрытия уже, а промахи сильнее влияют на детали. На лёгкой сложности зона шире, а промахи не наносят урон.

## 💾 Сохранения и файлы

Игра хранит пользовательские данные рядом с Python-скриптом:

| Файл | Назначение |
|---|---|
| `phone_flip_save_v3.json` | Прогресс игры; поддерживается перенос сохранений из v3 |
| `phone_flip_settings.json` | Настройки |
| `phone_flip_music_v1.wav` | Кэш сгенерированной фоновой музыки |

Эти файлы создаются во время игры. Необязательно добавлять личные сохранения и настройки в Git-репозиторий. Их можно исключить через `.gitignore`:

```gitignore
phone_flip_save_v3.json
phone_flip_settings.json
phone_flip_music_v1.wav
__pycache__/
```

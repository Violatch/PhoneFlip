# 📱 Phone Flip

**Phone Flip** — настольная игра-симулятор на Python и pygame: покупайте сломанные телефоны, чините их своими руками и перепродавайте с выгодой. Накопите **$50 000**, пока вас не съела аренда и долги.

![Экран ремонта](docs/repair_preview.png)

## Возможности

- **Ремонт руками.** Выкрутите винты, подденьте крышку, отключите аккумулятор, перетащите старые детали в мусорку, а новые — со стола в корпус, затем соберите всё обратно (7 шагов).
- **5 моделей телефонов** с собственными 3D-моделями: корпус, блок камер, экран, кнопки. Модели рендерятся программно, без внешних 3D-библиотек.
- **Повреждения видны:** трещины на экране и царапины на задней крышке.
- **Экономика:** рынок телефонов, магазин запчастей, инвентарь, продажа покупателям, еженедельная аренда.
- **Прокачка мастерской** (3 уровня).
- **Музыка и звуки** — lo-fi саундтрек и эффекты синтезируются прямо в игре.
- **Настройки:** громкость, анимации, качество 3D, сложность ремонта, полный экран, показ FPS, автосохранение.
- Интерфейс на русском языке.

![3D-модели телефонов](docs/3d_models_preview.png)

## Запуск

Нужен Python 3.8+ и pygame 2.x.

```bash
pip install pygame
python phone_flip_v4.py
```

Больше ничего устанавливать не нужно: музыка и звуки генерируются при первом запуске
(музыка кэшируется в `phone_flip_music_v1.wav` рядом со скриптом — можно положить готовый файл из репозитория).

## Правила игры

| Параметр | Значение |
|---|---|
| Стартовые деньги | $5 000 |
| Цель | $50 000 |
| Аренда | $250 каждые 7 дней |
| Предел долга | -$2 000 (дальше — банкротство) |
| Уровни мастерской | 3 (стоимость: $1 500 / $4 000 / $9 000) |

**Круг игры:** купить телефон на рынке → диагностика → заказать запчасти → отремонтировать → продать дороже.

Телефоны: iPhone 12, Samsung S21, Xiaomi 11, OnePlus 9, Google Pixel 6.
Детали: экран, батарея, камера, разъём зарядки.

## Управление

| Действие | Ввод |
|---|---|
| Выбор, перетаскивание деталей | Левая кнопка мыши |
| Прокрутка списков | Колесо мыши |
| Поддеть крышку | `Пробел` |
| Сохранить игру | `S` |
| Назад | `Esc` |
| Полный экран | `F11` |

## Сложность

| Уровень | Зона вскрытия | Ползунок | Урон деталям |
|---|---|---|---|
| Лёгкая | широкая | медленнее | меньше, промахи безвредны |
| Нормальная | обычная | обычный | обычный |
| Сложная | узкая | быстрее | больше |

## Сохранения

- `phone_flip_save_v3.json` — прогресс игры (совместим с сохранениями v3).
- `phone_flip_settings.json` — настройки.

Файлы создаются рядом со скриптом. Их стоит добавить в `.gitignore`.
